# Other schema formats (future)

This subtree is reserved for **maintainer-approved, project-scoped non-XML schema families** (such as JSON Schema, OpenAPI, or other domain-specific specifications), not for a single product.

Proposed layout: `formats/<registered-project>/<family>/vMAJOR.MINOR.PATCH/`.

**No non-XML manifest contract is standardized here yet.** Do not invent one or publish a stable non-XML family without a review of its canonical URI/path, version semantics, machine-readable metadata, validation and deployment requirements.

Project slugs must first be reserved in [`registry/projects.json`](../registry/projects.json). Read [`AGENTS.md`](../AGENTS.md) and [`CONTRIBUTING.md`](../CONTRIBUTING.md).

No released formats have been registered.
