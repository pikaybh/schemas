# BIXML Schemas

Public, independent namespace and future XML schema registry for Native BIM Markup Language research.

- Registry: https://pikaybh.github.io/schemas/
- Proposed namespace landing: https://pikaybh.github.io/schemas/openxmlformats/
- Implementation research: https://github.com/pikaybh/Xim

**Status: incubating; no normative BIM vocabulary or XSD is approved or published.**

This is not part of Microsoft's Office Open XML, schemas.openxmlformats.org, Ecma International, ISO/IEC, or buildingSMART.

## Deployment

GitHub Pages: deploy from branch, main, root directory. Pure static HTML with .nojekyll; no custom Actions workflows. GitHub's own Pages infrastructure may still run its internal deployment job.

## Next specifications

Publish versioned XML namespaces, XSDs, samples, semantic behavior contracts, migration policies, and independent engine conformance tests only after explicit architectural review. Do not change existing Xim BIMX file formats based on this provisional registry.
